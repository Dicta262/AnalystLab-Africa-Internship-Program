# AnalystLab Africa Data Analytics Internship Portfolio

## Overview

Welcome to my **AnalystLab Africa Internship Portfolio Repository**. This repository contains all projects, assignments, case studies, and practical exercises completed during my **8-week Data Analytics Internship Program at AnalystLab Africa** from **May 1, 2026 – July 1, 2026**.

Throughout the internship, I gained hands-on experience in data analysis, business intelligence, data visualization, SQL, Python programming, and data pipeline development. Each project in this repository demonstrates my ability to collect, clean, analyze, visualize, and interpret data to support data-driven decision-making.
